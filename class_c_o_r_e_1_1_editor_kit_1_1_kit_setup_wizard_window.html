Detailed Description

The frame of a Setup Wizard: what the project still needs for every included module — each check with a fix or a place to go, grouped by module. The required checks come first, then the optional ones, then the migrations off an obsolete API, each part under a summary of its own with its progress and "Fix all". A package derives it, adds a menu item and, if it wants, a footer; the checks are KitSetupCheck subclasses found by themselves.
