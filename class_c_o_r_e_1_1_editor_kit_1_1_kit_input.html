Detailed Description

Helpers for text fields. Keeps a field to the characters a value may hold: an id (a-z 0-9 _, typed capitals become small, spaces and dashes become _) or a name (A-Z a-z 0-9 _) — other keys do nothing, pasted text is cleaned. Gives a field a placeholder that works on every editor version.
