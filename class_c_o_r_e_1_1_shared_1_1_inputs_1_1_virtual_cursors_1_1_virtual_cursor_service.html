Detailed Description

The stick-driven cursor of the primary player (since v1.3): a real virtual Mouse device named VirtualMouseDeviceName that the UGUI input module follows like any mouse, plus simulated pointer events (IncludeUIMouseClick). Enabled by Enable and active only in the modes of VirtualCursorSettings.AllowedInputModes; leaving them warps the hardware mouse to where the cursor was. Reached through InputHost.VirtualCursor; Mouse.current is the virtual mouse while the cursor is active, so InputPointer and CustomCursor read it without changes.

What the cursor looks like: shown or hidden, the sprite.

The submit and movement actions of the cursor and the click they make.

The virtual Mouse device and the hardware mouse: creation and reclaim by name, state sync, deferred removal, the warp when the cursor goes away.

The per-frame motion: the stick, the speed shaper, the magnets, the pin to a moving target, the hover.

The UI module shares one pointer between every mouse, so the virtual button-up clicks whatever is under that pointer when the module processes it — the hardware warp's position included. Re-enabling the module drops its pointers (exit events, no click); the pressed object gets its pointer up (and the drag handler its end drag past the threshold) so nothing stays pressed.
