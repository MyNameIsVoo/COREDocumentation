Detailed Description

A package's identity in the editor windows: its name, color and glyph, and which assemblies are its. Every package built on the kit — CORE itself, a plugin, a plugin's DLC — declares exactly one, in its editor assembly; it is found by itself through TypeCache.

What a package adds to the windows — settings pages, checks, panels, manual chapters — is written as separate classes; each belongs to the module whose AssemblyPrefix its assembly name starts with (the longest prefix wins), so nothing has to be registered by hand. A plugin with several kinds of modules (a base and its DLCs) gives them a common base class and lists them with AllOf<T>.
