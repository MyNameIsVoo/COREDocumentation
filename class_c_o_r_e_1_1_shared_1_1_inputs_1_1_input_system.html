Detailed Description

The game's action assets next to CORE's: every InputActionAsset of every InputProjectSettings is served as a runtime copy (the asset on disk is never rebound), and any map of any asset gets a provider on demand.

Resolving actions to the runtime copies (since v1.3): an InputActionReference points at the asset on disk, whose actions are never enabled or rebound — every reference is translated to the action of the same id in CORE's Actions or a GameAssets copy, so rebinds and device detection see one action.

Interactive rebinding (since v1.3): one rebind at a time, on the runtime copy of the action (an override on the asset on disk would dirty it in the editor), of a binding of the keyboard-and-mouse group only. Gamepads, the mouse buttons and the pointer axes never complete a rebind; several cancel controls are allowed (SetCancelControlPaths), and a cancel by a gamepad button is not a Back of the navigation in that frame (IsRebindCancelPress).

Release callbacks and polling: for code that asks every frame (a held key moves the camera) instead of subscribing. A restricted group's map is disabled, so its inputs read as released and zero.

The binding overrides as a whole (since v1.3): clearing and resetting, the saved state and the way back to it, conflicts between bindings, other copies of the asset. The saved state is what Settings.Controls held when it was last applied (loaded or Settings.Apply); nothing here saves by itself.

Key icons of the current (rebound) bindings: the control path of a binding, the KeyCode it stands for (InputControlPaths) and the sprite of the Input resource entry for it.

Input system built on top of Unity Input System (GameInputActions). and the game's own assets (InputProjectSettings, GameAssets). Action maps are served by IInputProviders, one per InputKeyGenerated.InputGroups: a typed one registered by the game, or an InputMapProvider created the first time an input of the group is used. Groups can be restricted through IInvokeKeysListiner; a restricted group has its action map disabled. User binding overrides are stored in Settings.Controls and applied on load and on every Settings.Apply.
