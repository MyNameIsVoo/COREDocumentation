Detailed Description

Hides and locks the hardware cursor in the Gamepad mode and gives it back in Keyboard&Mouse (since v1.3). The state the game had set before the first Gamepad entry is what comes back; with InputCursorSettings.EnforceEveryFrame the lock is re-applied every LateUpdate, so other code showing the cursor loses while a gamepad is in use. CustomCursor only swaps the cursor image and is not affected.
