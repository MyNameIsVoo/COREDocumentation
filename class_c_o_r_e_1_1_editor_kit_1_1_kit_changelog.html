Detailed Description

The CHANGELOG.md of every installed package (<RootFolder>/CHANGELOG.md), newest version first: ## 1.3 — 2026-11-02 headings, then what changed. A Welcome window shows them and marks a package whose newest heading the user has not seen yet. A translation is a file next to it, CHANGELOG.<language>.md (CHANGELOG.ru.md), with the same headings: the Welcome window shows the one of the editor language and falls back to the English one.
