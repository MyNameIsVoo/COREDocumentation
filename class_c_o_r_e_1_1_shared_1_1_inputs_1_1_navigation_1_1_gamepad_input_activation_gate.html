Detailed Description

Holds the gamepad's UI input back right after the Gamepad mode is entered, until the sticks, the D-pad and the navigate action are neutral (since v1.3): the stick that was held to open a menu must not navigate the menu it just opened. Every provider, button and widget of the navigation checks IsInputAllowed.
