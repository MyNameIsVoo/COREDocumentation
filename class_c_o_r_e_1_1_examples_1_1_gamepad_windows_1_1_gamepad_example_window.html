Detailed Description

A window of the Gamepad page: its UIInputLayer enters the navigation when the window opens (the layer's AutoActivate) and leaves when it closes; B — the layer's BackRequested — closes it, so does the Close button for the mouse. The layer never closes anything itself: the window does.
