Detailed Description

A player's view of the navigation (since v1.3): a stable handle by player index that scene components resolve through UINavigationScope. The primary context (index 0) is attached while the host runs; a player's context is attached while the player is joined. Subscriptions survive detach and attach.

The navigation services of the context, attached by the host while the player plays.
