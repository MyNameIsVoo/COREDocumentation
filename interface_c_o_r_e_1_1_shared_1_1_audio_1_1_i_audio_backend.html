Detailed Description

The sound engine behind IAudioService: CORE's Unity backend or an adapter (FMOD, Wwise…). It only plays and mixes — settings, music, the catalog and muting rules live in AudioService. Volumes are linear 0–1. Created by an AudioBackendAsset assigned in AudioProjectSettings.
