Detailed Description

A CustomDropdown as a nested layer of the gamepad navigation (since v1.3): put it next to the dropdown and its UIInputElement. Submit opens the list as usual; in the Gamepad mode the open list becomes a layer of the dropdown's context — a vertical group of its items, the selected one focused — Submit picks an item, Back closes the list, and the focus comes back to the dropdown. With the keyboard and mouse nothing changes. ItemHint shows where the focus is in the list — CORE's UI_InputSelectionFramePrefab fits.
