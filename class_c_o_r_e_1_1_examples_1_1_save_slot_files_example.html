Detailed Description

A slot with a main file and one file per location; buildings and units save themselves through SaveGameCollection<TComponent,TData>. Type example.save_slot_files in the console: both locations are saved, location 2 is unloaded, location 1 is changed and saved alone — Location_2.json stays byte for byte the same; then location 1 is loaded into empty collections — buildings (priority 0) load before units (priority 10) although the units registered first, and every unit finds its home building by id. Runs on a slot of its own, deleted afterwards; the current slot of Model.LocationData is restored.
