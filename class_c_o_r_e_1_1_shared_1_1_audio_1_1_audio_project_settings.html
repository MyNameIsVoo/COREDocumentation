Detailed Description

Project-wide audio settings: the sound engine, which bus a clip of the generated catalog plays through, and the music started with the game. The game's own asset, Assets/Resources/AudioProjectSettings (outside the package, so an update leaves it and its backend asset alone), wins; without one the game runs on CORE's defaults, Resources/AudioProjectDefaults shipped with the package. The Setup Wizard check Audio: project settings and the Audio Editor create the game's own from the defaults.
