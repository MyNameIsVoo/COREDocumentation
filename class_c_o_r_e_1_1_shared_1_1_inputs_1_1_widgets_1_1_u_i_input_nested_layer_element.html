Detailed Description

A focusable panel with a layer of its own inside (since v1.3): Submit enters the nested layer (a dropdown's list, an inventory grid inside a row), Back leaves it and the focus comes back here. The nested layer must not auto-activate. A layer that is empty on Submit is retried next frame — the same Submit may be building its content; a layer that empties while entered is left by itself.
