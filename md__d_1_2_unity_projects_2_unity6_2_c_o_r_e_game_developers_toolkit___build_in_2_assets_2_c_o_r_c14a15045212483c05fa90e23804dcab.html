Custom UI elements, state machines, tables, modals

Namespaces: CORE.Shared.UI, CORE.Shared.UI.Custom, .Custom.Components, .Custom.Data, .Custom.State, .Custom.Table, .UI.Modal, .UI.Other. Source: Assets/COREToolkit/Scripts/Shared/UI/.

Create elements from the hierarchy context menu: GameObject/CustomUI/Prefabs/... (Button, Dropdown, Image, InputField, RaycastMask, ScrollView, Slider, Tabs, Text, Toggle) and GameObject/CustomUI/Components/State for a standalone StateMachineVisual. Use these instead of Unity's built-in UI objects — the CORE variants carry the state machine, color-library binding and localization hooks.

CustomImage.sprite hides Image.sprite (new, not an override): the CustomImage keeps its sprite in its settings and puts it back on every OnEnable. Set a sprite through a CustomImage reference (or ImageComponent.SetSprite) — written through an Image reference it shows until the object is next switched on, then the old (often empty — a white square) sprite comes back.

A CustomButton plays the sound of a state (its AudioComponent, keyed by the state name) when it enters the state, not when Unity re-applies the same state; every Submit plays its click.

CustomButton.EventClick passes the button itself, so one handler can serve several buttons: private void OnClicked(CustomButton button).

Unsubscribe on teardown. In a View that means Setup() / Sleep():

public override void Setup() { base.Setup(); Visual.Button.EventClick += OnClicked; }
public override void Sleep() { base.Sleep(); Visual.Button.EventClick -= OnClicked; }

Graphic components (text / image wrappers)

TextComponent, ImageComponent, RawImageComponent derive from CustomUIGraphicComponent, which binds the element to the Color Library: inspector fields Is Override Color, Color Tag (a ColorCustomGenerated.ColorEnums), Color Hash (_colorHash, palette hash), Is Override Alpha, Override Alpha.

Hash wins over tag. If _colorHash names a color the library knows, the color comes from the hash and the tag is ignored — so a prefab keeps its color in any project, whatever the enum numbers are there. Plugin prefabs keep _colorTag at 0 and rely on the hash. A runtime SetColor(ColorEnums) overrides the hash; SetColor(string hash) switches back to a hash. In the inspector (visible with the CORE_DEVELOPMENT define) picking a tag writes the hash too, the popup shows the tag the hash resolves to, and a label shows Palette / Color (or "no enum member yet" for a PlayerColorLibraryData palette).

text.SetText("literal");
text.SetText(42);
text.SetText(LocKeys.UI.Play); // localized, follows every language change
text.SetText(LocKeys.Shop.Coins, 21); // with {0} / {0:plural:...} arguments
text.SetText(LocKeys.Shop.Reward, new Dictionary<string, object> { ["gold"] = 5 }); // {gold}
text.SetTextOr("fallback", LocKeys.UI.Play); // the key if set, the string otherwise
text.SetArgs(5, 10); // new arguments for the current key
text.Refresh(); text.Key; // re-take the text / the key shown (LocKey.None = raw text)
text.SetColor(Color.red); // raw color
text.Component; // underlying TextMeshProUGUI
graphic.SetColor(ColorCustomGenerated.ColorEnums.DANGER_MAIN); // color-library color by tag
graphic.SetColor("9f6db18f-..."); // by palette hash
graphic.ColorData; graphic.ColorAlpha; graphic.ColorHash;
image.SetSprite(sprite);
rawImage.SetTexture(texture);

Prefer the Localization Key inspector field (a searchable picker of every table key, with its text) for static strings; leave it empty when the text is driven from code — SetText(string) also clears it. In play mode the font follows LanguageSettings.Fonts unless Use Language Font is off. New localization keys need code generation (see resources.md). The legacy SetText(LocalizeEnums) / SetText(LocalizedText) overloads are obsolete (removed in 1.4.0).

Localized images and sounds: LocalizedSprite / LocalizedAudioSource with a LocAssetKey (see resources.md).

State machine / transitions

Every custom element owns List<Transitions> Transitions (interface ICustomTransitionUiElement), authored in the inspector. A Transitions object binds a set of state names to one or more TransitionStateCollections:

ColorTransitions, Color32Transitions, SpriteTransitions, GraphicAlphaTransitions, CanvasGroupTransitions (incl. Interactable), GameObjectActiveTransitions (has a delay field), RectTransformTransition (position / size / LocalScale), AnimationTransitions.

Predefined state-name sets: Transitions.SelectionStateNames (Normal/Highlighted/Pressed/ Selected/Disabled), Transitions.OnOffStateNames, Transitions.ShowHideStateNames. Matching enums in CORE.Shared.Utils: DefaultStates, BoolStates, ScreenStates.

Standalone state machine on any object:

public class Door : MonoBehaviour
{
[StateMachine(typeof(BoolStates))] // or [DefaultStates], or [StateMachine("Open","Closed")]
public StateMachine States;
private void Open()
{
States.SetState(true); // bool overload
States.SetState(BoolStates.True, instant: true); // enum overload
States.SetState(0, instant: false); // index overload
}
}

StateMachine also exposes CurrentState and Awake() (call it if you create one in code). StateMachineVisual is the MonoBehaviour wrapper (States) created by GameObject/CustomUI/Components/State.

Transitions runtime API: SetState(name|index, instant), SetMode(TransitionMode), AddState, RemoveState, AddStates, RebuildStates, Awake(). TransitionStates.RemoveStateObject removes a state at runtime.

Editor previews of states are instant — no sounds, no tweens.

Tables

CustomTableVisual + CustomTableView render a pooled list of heterogeneous rows.

// 1. data type per row kind
public class RowData : CustomTableItemData
{
public readonly int Index;
public RowData(int index, Type visualType) : base(visualType) { Index = index; }
}
// 2. row Visual (must be listed in CustomTableVisual.ItemTemplates)
public class RowVisual : CustomTableItemVisual
{
public TextComponent Text;
private RowView _view;
public override void SetData(CustomTableItemData data) => _view.SetData(data);
public override void Clear() { }
protected override void Create(IView view)
{
_view = DiContainerRef.Container.Instantiate<RowView>(new object[] { this });
base.Create(_view);
}
}
// 3. row View
public class RowView : CustomTableItemView<RowVisual>
{
public RowData ItemData { get; private set; }
public RowView(RowVisual visual) : base(visual) { }
public override void SetData(CustomTableItemData data)
{
base.SetData(data);
if (data is RowData rowData)
{
ItemData = rowData;
Visual.Text.SetText(rowData.Index);
}
}
public override void Awake() { base.Awake(); /* re-apply, Awake is one frame late */ }
}
// 4. fill / clear
Table.TableView.Arrange(listOfRowData); // OnEnable
await Table.TableView.ArrangeBatchAsync(...); // large lists, spread over frames
Table.TableView.Add(rowData);
Table.TableView.Remove(rowData, destroy: false);
Table.TableView.Clear(); // OnDisable
Table.TableView.Items; // Dictionary<CustomTableItemData, CustomTableItemVisual>

CustomTableTextItemVisual/View + CustomTableTextItemData are the ready-made text row. Full example: Examples/Scripts/CustomUIExample.cs + Examples/Scripts/UI/ExampleCustomTableItem*.

For a small fixed table of plain MonoBehaviours, use the CustomTableField<T> struct (Setup() once, then Add() / Clear()).

Tabs

CustomTabsVisual.Items is TabsItemData[] { Name, IsActive, Toggle, Content }. Subscribe in Start(), not Awake() — TabsView is created by the View pipeline one frame later (or call Tabs.ForceCreate() first):

private void Start() { Tabs.TabsView.OnValueChanged += OnTabChanged; }

ResetActivePageOnEnable resets to the item whose IsActive is set. CustomTabsView.Reset() does it manually.

Modal prefabs also exist as resources: ResourcesGenerated.LoadVisualModal(new EnumData<ResourcesGenerated.ModalPrefabs>(...), root).

ProgressVisual (singleton) is the boot/long-operation banner: ProgressVisual.Instance.Set("text"), await ProgressVisual.Instance.Set("text", seconds), Hide(). From code that may run while the application quits (OnDisable, OnDestroy, settings applied when a screen hides) use ProgressVisual.Report("text"): it only logs while SingletonMonoBehaviour<T>.IsApplicationQuitting is set, when Instance is already null.

UI scaling, canvas, cursor, masking

[Zenject.Inject] private UIScaler _uiScaler;
Settings.Game.UIScaleFactor = (float)Math.Round(value, 2);
_uiScaler.OnGameSettingsChanged(Settings.Game); // apply
_uiScaler.Apply();
_uiScaler.Subscribe(componentScaler); // UIComponentScaler on a specific object

Bounds are GameSettingsData.MinUIScaleFactor / MaxUIScaleFactor (Examples/Scripts/UIScalerExample.cs).

UIComponentScaler is the per-object side: drop it on a RectTransform (and optionally a LayoutElement) that must follow the UI scale; it captures the authored sizes in Awake, subscribes itself to UIScaler, and Apply(scaleFactor) rescales them. Nothing to call by hand.

Inspector attributes

  • [CustomEnumPopup] / [CustomEnumPopup(CustomEnumPopType.Enum)] / [CustomEnumPopup("Label")] (CORE.Shared.UI.Custom): replaces the default enum dropdown with a searchable popup window, sorted alphabetically (Alphabet, default) or by enum value (Enum). Use it on any field typed with a generated enum, e.g. ColorEnums (localization and audio use LocKey / AudioKey, which have their own pickers); the plain dropdown becomes unusable past a few hundred members.
  • [ReadOnly] (CORE.Shared.Utils.Attributes): locked in the inspector, see systems.md.
  • [StateMachine(...)] / [DefaultStates]: see "State machine / transitions" above.

CanvasReference.Instance gives the main Canvas and its Size. GlobalVisual.OnValidate (editor only) forces its CanvasScaler.referenceResolution to PlayerSettings.defaultScreenWidth/Height; the runtime default size lives in GlobalConfig.Config.DefaultWidth/DefaultHeight.

CustomCursor (injected): SetState(ResourcesGenerated.CursourSprites type), SubscribeCatcher(MouseCatcher) / UnsubscribeCatcher. Put a MouseCatcher on anything that should change the cursor on hover (IsEnter, IsUp). CursorExtensions.IsVisible() reads the OS cursor state.

IMaskableHelper.SetMaskableWithoutRecursively(bool) and MaskableSwitchHelper toggle Maskable across a subtree — expensive, never per frame.

Gotchas

  • Anything reaching into visual.SomeView from another script must do it in Start() or after ForceCreate(); in Awake() the View exists but its own Awake() has not run yet.
  • GlobalVisual.Show(name) only finds visuals registered in the GlobalVisual inspector array.
  • CustomDropdown derives from Selectable, not from Unity's Dropdown — its OnValueChanged signature has three parameters.
  • Editor state previews are instant and silent; do not treat them as a runtime check.
