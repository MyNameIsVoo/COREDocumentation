Detailed Description

Reads and writes the files of a save slot. Writing is atomic: the json goes to <file>.tmp, which then replaces the file, so a crash in the middle leaves the previous file intact. Reading runs the SaveMigrations and the data migrations; types are named by SaveTypes.
