Detailed Description

The texts of the editor windows. Code holds keys only — Tr("configs.toolbar.save"); the words live in tables, one json per package and language, named <Scope>.EditorText.<lang>.json and kept in an Editor folder. Objects nest: {"configs": {"toolbar": {"save": "Save"}}} is the key above.

A key the chosen language lacks falls back to English, then to the key itself in brackets, and is remembered in MissingKeys. Keys of a package start with its module id (crafting., inventory.); the kit's own start with kit..

Not the game's localization: these tables are editor assets and never reach a build. The language is one setting for every kit window of every package, kept in EditorPrefs.
