Detailed Description

What to draw for an action or a binding (since v1.3). An action's icon and label come from InputGamepadSettings.ActionIcons for the gamepad family (the Generic entry is the fallback). A binding's text is the human-readable control path, always Latin whatever the keyboard layout; its icon is the InputGamepadSettings.ControlIcons entry of the path for the gamepad family (by default the family of the current gamepad), else CORE's key sprite of the path's KeyCode (UI_Icon_<KeyCode>_<size> of the Input resource entry).
