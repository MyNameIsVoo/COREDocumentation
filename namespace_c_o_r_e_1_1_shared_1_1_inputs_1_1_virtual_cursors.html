class  VirtualCursorService
 The stick-driven cursor of the primary player (since v1.3): a real virtual Mouse device named VirtualMouseDeviceName that the UGUI input module follows like any mouse, plus simulated pointer events (IncludeUIMouseClick). Enabled by Enable and active only in the modes of VirtualCursorSettings.AllowedInputModes; leaving them warps the hardware mouse to where the cursor was. Reached through InputHost.VirtualCursor; Mouse.current is the virtual mouse while the cursor is active, so InputPointer and CustomCursor read it without changes. More...

Shared by the primary virtual cursor (on top of its virtual mouse, with IncludeUIMouseClick) and the players' cursors (their only path to the UI).
