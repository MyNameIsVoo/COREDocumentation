Detailed Description

Keeps an icon or button readable on the Deck: the rect grows to the minimum side (both sides by the same factor with KeepAspect, else each clamped). The growth is added to sizeDelta, so anchored and stretched rects both work. Under a layout group the size is the group's — give the object a LayoutElement and wire it, the adapter raises its minimums.
