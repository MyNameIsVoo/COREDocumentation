Detailed Description

Rebinding the keyboard key of Player/Jump, step by step: Rebind waits for a key on the keyboard (Esc cancels; gamepads and the mouse's clicks never complete a rebind), the new key lands in Settings.Controls and is saved by Settings.Apply; Reset brings the asset's key back. The line below shows the key in effect and lights up when it is pressed — try the key before and after.
