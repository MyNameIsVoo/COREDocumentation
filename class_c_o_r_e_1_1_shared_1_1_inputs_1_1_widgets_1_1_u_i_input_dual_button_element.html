Detailed Description

A focusable row with two shortcut buttons (since v1.3) — "Equip" and "Drop" on an inventory slot: the buttons' bindings are live only while this element is the focus in the Gamepad mode, so the same two actions can serve every row. No Selectable and no focus target of its own.
