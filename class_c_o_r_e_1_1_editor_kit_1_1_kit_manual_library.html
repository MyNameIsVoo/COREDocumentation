Detailed Description

Every chapter of every installed package, in the editor's language where a translation exists and in English otherwise. Chapters are Markdown files in any Manual/<language>/ folder inside an Editor folder under Assets (an editor folder, so they never reach a build); a package that is not installed has no chapters, so a manual always matches what is in the project.
