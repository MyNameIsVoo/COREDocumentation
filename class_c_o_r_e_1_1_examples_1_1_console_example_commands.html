Detailed Description

Console commands of the example game. Static members with ConsoleCommandAttribute are found on start; ConsoleCommandPrefixAttribute puts them under example.. Open the console with the key from the Console settings (` by default) and type help example; the Console page of the examples scene (ConsoleExample) drives them through ConsoleHub.
