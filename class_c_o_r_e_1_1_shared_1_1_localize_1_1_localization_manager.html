Detailed Description

The legacy side of the localization, removed in LegacyLocalization.RemovedIn: the old API returning LocalizedText, LocalizedText assets not yet migrated to tables, and the sync with GameToolkit.Localization.Localization.Instance both ways.

CORE localization: CSV tables (Key, Comment, en, ru, …) declared under the Localize resource paths, one column per language. Every lookup goes current language → its parent (pt-BR → pt) → LanguageSettings.FallbackLanguage. Tables registered at runtime (mods) override the project's ones key by key, by priority.

Localized assets: one file per language under <Group>/<language>/ of a Localize path. An asset is loaded on demand from its bundle and taken by the same chain as texts: current language → parent → fallback language → any language that has it.
