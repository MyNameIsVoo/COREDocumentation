Detailed Description

A cue authored in Resources/Configs/audio.json (and its fragments audio.<part>.json): the id is the AudioKey, Clips are clip names of the generated catalog (file names without extension). An id equal to a clip name overrides how that clip plays.

"Footstep": { "Clips": ["Footstep_0", "Footstep_1"], "Bus": "Effects", "PitchMin": 0.9, "PitchMax": 1.1, "Spatial": true }
