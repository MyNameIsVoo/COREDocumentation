Detailed Description

An additional file of a save slot (Location_3.json next to SaveData_<Id>.json): the data of the ISaveGameFileComponents whose ISaveGameFileComponent.SaveFile is its name. Saved and loaded on its own by SaveSystem; the id counter of the slot stays in SaveData.
