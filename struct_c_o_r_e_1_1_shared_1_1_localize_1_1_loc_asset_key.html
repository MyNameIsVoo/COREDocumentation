Detailed Description

A key of a localized asset — a sprite, an audio clip, any asset that differs per language. The asset of a language is the file <Group>/<language>/<Key>.* under a Localize path (Localization/Sprites/ru/Logo.png). Serialized as the key itself; generated constants live in LocAssets.<Group>.<Key>. Compared case-insensitively.
