Detailed Description

Marks a static method, property or field as a console command. A property or field gives two commands: name reads it, name value writes it. Several attributes on one member are aliases. The attribute only describes; which console picks it up is decided by the installed backend (see ConsoleHub), so it may stay on the code when no console is installed.
