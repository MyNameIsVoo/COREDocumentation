Detailed Description

A sound: the id of a cue of the audio catalog (a clip file name, an audio.json entry or a runtime registration) or, with a third-party backend, its event (FMOD: event:/UI/Click). Serialized as the id itself, compared case-insensitively. Generated constants live in AudioKeys.
