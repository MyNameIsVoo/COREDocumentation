Detailed Description

Regenerate references/api-surface.md from the CORE sources.

Usage (from the project root):
    python Assets/COREToolkit/AI/Skills/core-toolkit/scripts/dump_api.py .

Scans Assets/COREToolkit for public/protected declarations and writes a grep-friendly
index grouped by file and namespace into ../references/api-surface.md next to this script
(works both for the packaged copy and for the copy installed into .claude/skills).
