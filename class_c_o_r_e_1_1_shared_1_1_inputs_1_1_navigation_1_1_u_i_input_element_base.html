Detailed Description

The base of every focusable element (since v1.3): finds its UIInputGroup and Selectable in the parents, registers with the group while enabled, answers whether the focus may land on it — the Selectable's interactability, the CanvasGroup chain, its own rule, the availability components next to it and the game's restrictions.

The hint of the element, highlighted while the element is focused.
