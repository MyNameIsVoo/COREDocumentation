Detailed Description

Tells which device the player is meaningfully using (since v1.3): every triggered action of CORE's asset and the game's copies is weighed by its control's magnitude against the settings' thresholds, and the current gamepad, keyboard and mouse are polled every tick so a device counts even while no map of it is enabled. A mouse's absolute position never counts (a warp must not switch the mode), nor does a non-native mouse (the virtual cursor), nor the mouse inside the suppression window of SuppressMouseDeviceUsed.
