Detailed Description

A provider for any action map, found by the group's name in CORE's asset or a game asset of InputProjectSettings: no generated callbacks interface, no hand-written class per map. Created by InputSystem.RegisterProvider(InputKeyGenerated.InputGroups), or by InputSystem itself the first time an input of the group is subscribed or polled. A typed provider registered later for the same group takes its subscriptions over.
