class  SaveGameCollection< TComponent, TData >
 Saves every registered entity of one kind (buildings, units, items) as one SaveGameCollectionData<TData>. Each entity decides what to save in ISaveGameComponent<TData>.CollectData; the collection only gathers. On load an entity gets its data by ISaveGameComponent<TData>.Id; data with no registered entity goes to the factory, which creates the entity. After every component of the load got its data, ResolveReferences lets each entity that implements ISaveGameReferences find others by id. Register the collection itself in SaveComponentsManager. class  SaveMigrations
 Migrations of save files. A file stores the CurrentVersion it was written with (Data.SaveFileBase.FormatVersion); reading an older file runs every migration above its version, in order, on the raw json — before it becomes objects, so renamed and moved fields can still be read. Register at boot, before the first save is read. A component's own data migrates with Data.SaveGameBaseComponentData.Migrate. More...
