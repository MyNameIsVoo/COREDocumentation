Detailed Description

Raw keys without UnityEngine.Input (InputSystem.Keyboard): the modifiers a selection or a drag checks, and any Key for code that is not an action yet. Everything reads as released while every group is restricted (the console, a save, a listener's override) — a bound action is the better tool: it is rebindable and restricted per group.
