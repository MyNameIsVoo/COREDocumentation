Detailed Description

A save component that says which file of the slot it writes to and when it loads. CORE.Shared.Save.SaveSystem calls ISaveGameBaseComponent.LoadData of such a component itself, in LoadPriority order; a plain ISaveGameBaseComponent still gets its data only through OnLoadingComplete.
