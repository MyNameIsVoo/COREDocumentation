Detailed Description

Marks a string config field that names an entry of another config by its id, written as a plain string rather than through a config reference converter — a trader's layout, a blueprint's recipe. With a Prefix the id is the prefix plus the value: a recipe's station workbench names the layout crafting_station_workbench. Read by the config editor, which offers the ids and checks them. No effect at runtime.
