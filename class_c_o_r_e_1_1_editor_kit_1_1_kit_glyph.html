Detailed Description

A line icon drawn as vectors, so it is sharp at any size and takes the color of the text around it.

Written on a 24×24 grid as parts split by ;, each stroked, or filled when it starts with *. Commands, absolute only: M x y, L x y, H x, V y, C x1 y1 x2 y2 x y, Q x1 y1 x y, Z, plus O cx cy r (circle) and R x y w h r (rounded rectangle).
