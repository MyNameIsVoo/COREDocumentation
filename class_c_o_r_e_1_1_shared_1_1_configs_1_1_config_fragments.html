Detailed Description

Lets a module or a DLC add to and patch a config without editing its file. Next to the base items.json, any Resources/Configs folder may ship fragments named items.<anything>.json. The base applies first, then the fragments by file name, ordinal.

For an entry an earlier file already declares: object properties merge recursively, scalars and arrays replace, "Name+": [...] appends to the array Name, and an object holding "$remove": true removes the entry or property it stands for. An unknown id is added.

An entry that only appends (IsPatchOnly: every property a "Name+") is a patch, never a declaration: for an id no file has declared yet it waits until every file is applied, then patches the entry if some later file declared it, and is dropped otherwise. That is how a package adds data to entries of a package that may not be installed — Trading pricing a Crafting item — without making half an entry when it is not.

Every id reaches CORE once, already merged: ConfigList<T> Insert adds an id to its List again each time it is called, so inserting per file would duplicate entries.
