Detailed Description

Controls the text and its localization on a TextMeshProUGUI: a LocKey set in the inspector or from code is shown in the current language and follows every language change; a raw string set from code is shown as it is. In play mode the font follows LanguageSettings.Fonts.

The GameToolkit-era data of the component, removed in LegacyLocalization.RemovedIn: the serialized LocalizeEnums number becomes the LocKey of the same name the first time the component is validated, the LocalizedTextBehaviour next to it is switched off.
