Detailed Description

The FMOD Studio adapter (compiled with the CORE_FMOD define, set by the Setup Wizard once FMOD for Unity is in the project). A key plays the event of its Events mapping, otherwise the event of its id: event:/UI/Click, or UI/Click with the prefix added. Every AudioBus maps to a bus or VCA path, every snapshot id to a snapshot event. Unity clips — IAudioService.PlayClip and catalog cues with no event — play through a Unity backend next to FMOD.
