Detailed Description

A chapter's Markdown as UI Toolkit elements: headings (anchored), paragraphs, bullet and numbered lists, tables, fenced code, quotes as callouts (> [!NOTE], [!TIP], [!WARNING], [!CAUTION]), images, rules. Enough of GitHub Markdown for a manual, nothing more.
