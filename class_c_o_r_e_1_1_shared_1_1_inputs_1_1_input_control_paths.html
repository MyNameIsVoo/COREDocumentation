Detailed Description

KeyCode ↔ Input System control path (<Keyboard>/i, <Mouse>/leftButton, <Gamepad>/buttonSouth): turns legacy key data into bindings once (ToControlPath) and a binding back into the key its icon is named after (ToKeyCode; the Input sprites are UI_Icon_<KeyCode>_<size>). Gamepad buttons are the Xbox layout of KeyCode.JoystickButton*.
