Detailed Description

Feeds a player's navigation from the navigate, submit and cancel actions (since v1.3): the direction with a deadzone, hysteresis on diagonals and key repeat; submit and cancel on performed. Runs in the Gamepad mode only, and only while the activation gate lets the input through.
