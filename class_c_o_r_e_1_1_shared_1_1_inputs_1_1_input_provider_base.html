Detailed Description

Base provider. Stores subscribers per input and invokes them from the action callbacks. A derived class implements the generated callbacks interface of its action map and calls Invoke(InputKeyGenerated.InputEnums, InputAction.CallbackContext) from every callback: performed reaches the pressed subscribers, canceled the released ones.
