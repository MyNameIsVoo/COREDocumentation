Detailed Description

Marks a string field (or each string of a string array) that names something the game defines elsewhere — a slot of a layout, an input action, an asset bundle. The config editor offers the names its choice source lists and flags one it does not know. Source is the id of a choice source in the editor (CORE.Editor.Configs.ConfigChoiceSource); a package declares its own ids, prefixed with its module id (inventory.slot). No effect at runtime.
