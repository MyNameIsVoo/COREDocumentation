Detailed Description

The base of every window built on the kit: the theme, a header with the module's tile and a help button, the content, a status bar, toasts. The whole tree is built in code by BuildContent and built again when the editor language changes, so a window keeps no text of its own outside it.

The header takes the window's identity from the KitModule of its assembly — override Glyph and Accent only to differ from it. Keep state that must survive a rebuild — the selection, a scroll position — in serialized fields, and set it back at the end of BuildContent.
