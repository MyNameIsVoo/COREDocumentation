Detailed Description

A UI element the virtual cursor is pulled towards when it comes close (since v1.3): put it on a button so the stick lands on it. The pull radius and speed come from VirtualCursorMagnetSettings; the radius may be overridden per magnet. Enabled magnets register themselves in Active.
