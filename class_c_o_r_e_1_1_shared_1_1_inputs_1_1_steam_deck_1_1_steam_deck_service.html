Detailed Description

The Steam Deck readability mode (since v1.3): minimum text and image sizes the SteamDeck*Adapters of the scene enforce while the mode is on. Detects the Deck once (the editor simulation, the SteamDeck environment variable the Steam client sets, the device model keywords); starts on by SteamDeckSettings.EnabledByDefault or on a Deck with SteamDeckSettings.AutoEnableOnSteamDeck. The player's choice is not saved here — the game keeps it and calls SetEnabled. The toggle hotkey works in the editor always and in a build while CheatAllowed.
