Steam: init and Inventory

Namespaces: CORE.Shared.Steam, CORE.Shared.Steam.Debug, editor CORE.Editor (builder). Backed by Steamworks.NET (ThirdParty/com.rlabrecque.steamworks.net), which is compiled only for Editor + Windows/macOS/Linux standalone. Guard Steam code with the same platform defines CORE uses:

#if UNITY_STANDALONE_WIN || UNITY_STANDALONE_LINUX || UNITY_STANDALONE_OSX || STEAMWORKS_WIN || STEAMWORKS_LIN_OSX

Enabling Steam

  • App id goes in steam_appid.txt at the project root and in GlobalConfig.Config.AppId / SteamId (AppId_t); build version in SteamGameVersion.
  • In the editor, Steam init is gated by the Enable Steam toggle in Tools/CORE/Game Window (SteamManager.HasEnabledSteam, stored in PlayerPrefs under SteamManager.EnableSteamPlayPrefsKey). The Steam client must be running.
  • In a standalone build the toggle does nothing: Steam is initialized unless the scripting define CORE_DISABLE_STEAM (SteamManager.DisableSteamDefine) is set for the Standalone target — the Steam in builds toggle on the same page adds/removes it. SteamManager.IsEnabled is the single answer (toggle in the editor, define in a build); gate your own Steam boot code on it.
  • Before building, set Steam up or turn it off. Set up = app id in GlobalConfig, steam_appid.txt next to the executable (or launch from Steam), Steam client running under the same OS user, app owned by the account; otherwise SteamAPI_Init() failed in the player log. Never use Steamworks.NET's DISABLESTEAMWORKS — it strips the Steamworks types and CORE stops compiling.
  • GameApplication.Awake waits for Steam before anything else (SteamManager.WaitForSteamLaunch() in builds), then calls SteamManager.Instance.InitServices() late in boot.

There is no Core.Get<T>() despite what the docs show — reach the manager via SteamManager.Instance.Inventory, or inject it if you bind it in your own installer.

Steam Cloud is toggled from Settings.Game.SteamClouds and applied during boot.

Authoring items (editor)

  1. Create → CORE/SteamInventory produces a SteamInventoryBuilder ScriptableObject.
  2. Set the App ID and fill the Items array: id, name, type, quality, tags, icons, price, etc.
  3. Build JSON validates (unique ids, valid relations) and writes SteamInventory.json.
  4. Upload that file to the Item Store in the Steamworks partner site.

Runtime: SteamInventoryManager

var inventory = SteamManager.Instance.Inventory;
await inventory.Init(); // load item definitions (done during boot)
inventory.HasLoadedItemDefinitions;
inventory.IsInventoryReady;
inventory.IsActiveChangingItems;
inventory.Items; // SteamItem[] — definitions
inventory.PlayerItems; // Dictionary<uint, SteamPlayerItem> — what the player owns
// events
inventory.OnChange += manager => { }; // any inventory update
inventory.OnItemAdded += items => { }; // List<SteamPlayerItem>
inventory.OnInventoryResult += manager => { };
// operations (all UniTask)
await inventory.GrantItemToPlayer((SteamItemDef_t)101, 1);
await inventory.GrantItemsToPlayer(new[] { (SteamItemDef_t)101, (SteamItemDef_t)102 }, new uint[] { 1, 5 });
await inventory.ConsumeItem(itemInstanceId, quantity);
await inventory.ExchangeItems(listOfSteamPlayerItems); // also List<SteamItemDef_t> / (ids, quantities)
await inventory.TriggerDropRandomLoot(listOfItemDefs);
await inventory.TriggerPeriodicDropRandomLoot(maxRetries);
await inventory.GrantPromoItem(itemDef);
inventory.RequestPromoItems();
await inventory.GetPlayerItemsAsync(); // (SteamItemDetails_t[] Items, bool IsActual)
inventory.GetItemQuantity(itemDefId); // also overload by SteamItemInstanceID_t
inventory.GetItems(steamItemDetailsArray);

Results come back as SteamInventoryManager.ResponseData { ClientWarning Result, SteamItemDetails_t[] Items }. ClientWarning is CORE's friendly wrapper over EResult (EResultExtensions.ToClientWarning() in GameEnums.cs) — surface that to the player rather than the raw Steam code.

SteamInventoryManager.Update() must be pumped (SteamManager does it); Destroy() tears down.

Data models

SteamItem — an item definition: Definition (SteamItemDef_t), Quality (Quality enum), SteamTag (ItemSteamTag), EventTag, and Attributes (Dictionary<ItemValueType, ItemValueData> with ValueInt / ValueBool / ValueString).

SteamInventoryManager.ItemValueType mirrors the Steam item schema: ItemDefId, Name, Type, Bundle, Tags, StoreTags, Marketable, Tradable, Hidden, NameColor, IconUrl, IconUrlLarge, AutoStack, Promo, PriceCategory, ItemSlot, Description, BackgroundColor, DisplayType, DropStartTime, Exchange, Price, TagGenerators, TagGeneratorName, … . SteamInventoryManager.Attributes maps each to (string Name, uint BufferSize).

SteamPlayerItem — an owned instance: Item (the SteamItem), ItemDetails, Quantity, IsValid, event Action<SteamPlayerItem> OnChange, Update(details), MarkAsDestroy().

Quality extensions (CORE.Shared.Utils.GameEnums): ToColorTag(), ToColorHTML(), ToVLV(), IsExchangingAvailable() — use these for rarity colouring instead of hardcoding. ItemSteamTag has the same colour extensions. SteamInventoryManager.AmountItemsToExchangeRarity is the crafting/exchange constant.

Debugging

DebugSteamInventory (MonoBehaviour, custom inspector in Scripts/Editor/Game/Steam/DebugSteamInventoryEditor.cs) exposes buttons for every operation: LoadItemDefinitions, GetAllItems, GrantItemsToPlayer, ConsumeFirstItem, ExchangeItems, DropRandomLoot, GrantPromoItems, etc. Console commands live in Scripts/Shared/Console/SteamItemsConsoleCommands.cs.
