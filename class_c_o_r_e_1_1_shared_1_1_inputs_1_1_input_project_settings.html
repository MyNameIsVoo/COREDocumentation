Detailed Description

The action assets of a game, next to CORE's own Resources/InputSystem_Actions.inputactions (which a package update overwrites, so a game never edits it). Any number of these assets, in any Resources folder, any name — a game and every package it installs declare their InputActionAssets in one of their own (Create/CORE/Input/Input Project Settings); deleting the folder takes its maps with it. InputSystem serves every map of every asset; code generation writes InputGroups / InputEnums for them, so map names must be unique across the assets (the Setup Wizard check Input: project settings warns).
