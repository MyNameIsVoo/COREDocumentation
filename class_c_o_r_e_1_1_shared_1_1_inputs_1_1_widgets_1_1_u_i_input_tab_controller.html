Detailed Description

Tabs switched by two shortcut buttons (the shoulders) or by clicking the tab buttons (since v1.3): the active tab's content group is enabled and focused, the others hidden; the tab buttons show Selected. A tab marked HideOnGamepad disappears in the Gamepad mode. State is applied after every LateUpdate of the frame, because the host restores the focus in LateUpdate.
