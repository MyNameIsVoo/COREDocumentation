Detailed Description

The GameToolkit-era texts of a mod, removed in LegacyLocalization.RemovedIn. Mods and export settings saved before keep Name/Author/Description as LocaleItem<T> arrays: they are read into the new fields on load (JSON and Unity serialization), and are written back on save so a game on an older CORE still shows the mod's texts.
