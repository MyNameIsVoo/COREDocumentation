Detailed Description

The Console page of the examples scene: what game code does with ConsoleHub — opens and closes the window, runs a line as if typed, prints its own line, follows ConsoleHub.OpenChanged. The commands it runs are declared in ConsoleExampleCommands; the key that opens the window and everything else is in Tools/CORE/Settings → Console.
