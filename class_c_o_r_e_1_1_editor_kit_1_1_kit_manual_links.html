Detailed Description

What a link in a chapter does:

  • https://… — opens the browser;
  • #anchor — scrolls to a heading of the chapter;
  • chapter-id, chapter-id#anchor — opens a chapter (a .md file name works too);
  • open:<action>[/argument] — opens a window: open:gallery, open:settings/core.editorWindows. A package adds its own with Register, prefixed with its module id where the name may clash.
