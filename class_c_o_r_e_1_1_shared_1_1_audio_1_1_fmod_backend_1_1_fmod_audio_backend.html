Detailed Description

The buses of FmodAudioBackend: an AudioBus sets the volume and pause of its FMOD bus or VCA; until that is found (a bank not loaded yet, retried every second) or with no path, the volume scales CORE's instances of the bus and pausing pauses them.

Sample data: a preload loads the event's samples (FMOD counts the loads, so each key is loaded once here and unloaded once); a key with no event preloads its catalog clips through the Unity clips.

IAudioBackend on FMOD Studio, set up by a FmodAudioBackendAsset. A handle is a slot of an EventInstance with a generation; volume fades and the start delay of the API run on top of the event's own (a stop lets the event fade out unless FmodAudioBackendAsset.AllowFadeOut is off). Parameters are the event's; a global parameter is a Studio global one. Looping, voice limits and routing are authored in FMOD, so AudioPlayOptions.Loop and AudioPlayOptions.Bus only file the instance for StopAll and pausing.

Unity clips next to FMOD: PlayClip and catalog cues with no event play through a UnityAudioBackend created on the first such play. Its handles have a negative id (~id), so one handle space covers both engines; bus volumes and pauses reach it too.
