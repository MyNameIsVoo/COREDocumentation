Detailed Description

A part of a package with a version of its own — the audio of a framework, the crafting of an inventory. It has a color, and a changelog marks every change with the dot of its part: a list item starting with {audio}. A package lists its parts in KitModule.Parts; the Welcome window shows them as tiles.
