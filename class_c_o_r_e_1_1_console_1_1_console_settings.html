Detailed Description

Project-wide console settings. The game's own asset, Resources/CoreConsoleSettings, wins; without one the console runs on CORE's defaults, Resources/CoreConsoleDefaults shipped with the package; without either — the values below. Edited in Tools/CORE/Settings → Console; the asset is plain data so the console stays independent.
