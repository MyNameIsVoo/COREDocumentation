Detailed Description

The EventSystem and its InputSystemUIInputModule on behalf of the gamepad support (since v1.3). CORE's own navigation owns move/submit/cancel in the Gamepad mode (or while a module locks it): the module's three references are taken away and given back in Keyboard&Mouse, so directional navigation has exactly one owner. With EventSystemPolicy.UseExisting the modules of the scene's EventSystem are never added or removed; EventSystemPolicy.CreateIfMissing creates one when the scene has none. Follows EventSystem.current when the tracked one is destroyed; a working one is never replaced.
