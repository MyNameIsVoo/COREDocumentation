Detailed Description

The gamepad support of CORE (since v1.3), on top of InputSystem: input modes and the active device, UI navigation, prompts and icons, the virtual cursor, haptics, Steam Deck readability. Built by ProjectInstaller, it creates the services in a fixed order (their subscriptions depend on it), ticks them through GlobalUpdater on unscaled time and disposes them in reverse. Services are reached through its properties: the required ones throw before IsInitialized, the optional ones are null.

The services of the host: created in CreateServices in the order their subscriptions require, ticked in TickServices and LateTickServices, disposed in reverse in DisposeServices. Every part of the gamepad support adds its service here.

Subscriber order of InputModeService.InputModeChanged: gate → bindings → hints → cursor control → virtual cursor → haptics → navigation → InputModeChanged → the contexts' UINavigationContext.ModeChanged. Of InputHost.InputModeChanged: UI first, then the navigation input providers, then the game. Of InputDeviceService.ActiveDeviceChanged: gate → haptics → InputModeService.NotifyDeviceChanged → ActiveDeviceChanged. The players (local multiplayer) are created after every service and disposed before them: a module detaches before any service goes.
