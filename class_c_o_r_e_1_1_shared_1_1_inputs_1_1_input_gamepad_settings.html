Detailed Description

Gamepad support settings (since v1.3): input modes and device detection, UI navigation, button icons, virtual cursor, haptics, Steam Deck, local multiplayer. The game's own asset, Resources/CoreInputSettings, wins; without one CORE's defaults, Resources/CoreInputDefaults shipped with the package; without either — the values below. Edited in Tools/CORE/Settings → Input. Action references left empty fall back to CORE's UI and VirtualCursor maps by name.
