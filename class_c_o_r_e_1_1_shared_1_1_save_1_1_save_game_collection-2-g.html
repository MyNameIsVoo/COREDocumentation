Detailed Description

Saves every registered entity of one kind (buildings, units, items) as one SaveGameCollectionData<TData>. Each entity decides what to save in ISaveGameComponent<TData>.CollectData; the collection only gathers. On load an entity gets its data by ISaveGameComponent<TData>.Id; data with no registered entity goes to the factory, which creates the entity. After every component of the load got its data, ResolveReferences lets each entity that implements ISaveGameReferences find others by id. Register the collection itself in SaveComponentsManager.
