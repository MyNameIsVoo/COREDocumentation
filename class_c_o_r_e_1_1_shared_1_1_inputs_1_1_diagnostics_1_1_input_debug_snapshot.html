Detailed Description

The state of the gamepad support at one moment, for a player's context: the mode and devices, the prompts and the gate, the cursor, haptics and Steam Deck, the EventSystem, the navigation stack with the focus, the layer's groups and elements, the enabled maps with their actions, the devices. Built by InputDebugService.BuildSnapshot; plain data, safe to keep.
