Detailed Description

The Steam Deck readability mode: minimum text and image sizes the SteamDeck*Adapters enforce. Sizes are in canvas units, not Deck pixels: a 1920x1080 canvas on the 1280x800 screen scales by 0.667, so Valve's 12 px minimum is a font size of about 20.
