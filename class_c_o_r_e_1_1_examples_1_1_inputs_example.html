Detailed Description

The Inputs page: CORE's Player map through a typed provider (ExampleInputProvider), and the examples' own map Example of Examples/Inputs/ExampleInputActions.inputactions, registered by Examples/Resources/InputProjectExamples (an InputProjectSettings) and served without a provider class: a press / release subscription, a held Vector2 and an axis polled every frame, the icon of the current binding and an interactive rebind kept in the settings.
