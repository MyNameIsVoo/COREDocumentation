Detailed Description

The binding group of the keyboard and mouse (since v1.3): the only group whose bindings the player may rebind. Resolved from the asset's control schemes, so an asset that calls the scheme "PC" or "KBM" still works; the runtime, the editor and any binding syncer use the same resolver.
