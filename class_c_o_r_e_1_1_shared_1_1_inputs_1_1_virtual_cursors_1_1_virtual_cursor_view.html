Detailed Description

The image of a virtual cursor on an Overlay canvas of its own (since v1.3). Built in code by default; a game gives its own prefab through VirtualCursorSettings.CanvasPrefab with this component on the root or a child and the image wired. The image is active only while visible and with a sprite.
