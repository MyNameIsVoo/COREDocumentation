Detailed Description

The pointer without UnityEngine.Input: the mouse, or the first touch when there is no mouse (InputSystem.Pointer). Position and delta are always read — the UI needs them; buttons, scroll and touches read as released and zero while every group is restricted (the console, a save, a listener's override).
