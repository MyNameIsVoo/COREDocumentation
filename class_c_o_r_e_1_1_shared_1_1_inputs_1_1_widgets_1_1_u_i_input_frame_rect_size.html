Detailed Description

Feeds the CORE/UI/InputFrame shader (since v1.3) — a solid rounded outline: writes the normalized rect coordinates into uv0.zw of every vertex and the rect size in pixels into an instance of the material, so the frame's line keeps its width whatever the sprite, the atlas, the Image type or the frame's size. Put it on the Image of the frame.
