class  ConsoleCommandAttribute
 Marks a static method, property or field as a console command. A property or field gives two commands: name reads it, name value writes it. Several attributes on one member are aliases. The attribute only describes; which console picks it up is decided by the installed backend (see ConsoleHub), so it may stay on the code when no console is installed. More...

 Prefix of every ConsoleCommandAttribute name in the class: [ConsoleCommandPrefix("player.")] turns heal into player.heal. More...

class  ConsoleExecutor
 Runs a typed line: picks the overload by argument count, parses the arguments, invokes, prints what came back — a value at once, a Task when it finishes, an IEnumerator as a coroutine. More...
 
class  ConsoleHistory
 The lines typed before, newest last, kept across runs in PlayerPrefs; ↑ / ↓ walk it. More...
 
class  ConsoleHost
 The one object the console lives on. Creates itself before the first scene when the settings allow it, owns the backend and the IMGUI window, and needs nothing from the scene, the DI or the input setup — so it is there even when the game failed to initialize.
 
class  ConsoleHub
 The one entry point game code talks to. Without a backend (the console assembly is disabled, or none is installed) every call is a no-op and IsOpen is false; registrations made before the backend arrives are replayed into it. More...
 
class  ConsoleLog
 The entries, from the Unity log (any thread) and from the console itself, capped at the newest MaxEntries, with the counts per kind. Readers take a snapshot under Sync. More...
 
class  ConsoleLogCommands

class  ConsoleLogger
 The console's own logging. The console references no other assembly, so it cannot use CORE's DebugHelper; every line is prefixed so it is still found at a glance.
 
class  ConsoleMetrics

class  ConsoleRegistry

class  ConsoleScanner
 Reflection over assemblies and objects: finds the ConsoleCommandAttribute members, the ConsoleParserAttribute classes and the old [IngameDebugConsole.ConsoleMethod] methods. Pure reflection, so it may run on a worker thread; the result is committed to a registry on the main thread. More...
 
class  ConsoleSceneCommands
 scene.load, scene.restart, scene.list — off with ConsoleSettings.SceneCommands. Loads through SceneManager directly, so a game with its own loader may turn the group off.
 
class  ConsoleSettings
 Project-wide console settings. The game's own asset, Resources/CoreConsoleSettings, wins; without one the console runs on CORE's defaults, Resources/CoreConsoleDefaults shipped with the package; without either — the values below. Edited in Tools/CORE/Settings → Console; the asset is plain data so the console stays independent. More...
 
class  ConsoleStyles
 The GUIStyles of the window, built from the theme at the current metrics. Flat: one white texture tinted through GUI.color draws every fill, the styles only carry fonts and padding.
 
class  ConsoleTheme
 The colors of the window and of every message type. More...
 
class  ConsoleTimeCommands

class  ConsoleTokenizer
 Splits a typed line into statements (;) and a statement into tokens: whitespace separates, quotes keep spaces, ( ) [ ] { } keep what is inside together, </c> escapes. More...
 
class  ConsoleUiBlock
 Keeps clicks on the window from reaching the game's uGUI: while the console is open the scene's EventSystem is disabled and enabled back on close. Found by name — the console references no UI package, and a game without one is left alone.
 
class  ConsoleView
 The IMGUI window: docked to the top edge, full width, slides down when opened, resized from its bottom strip. Drawn from ConsoleHost's OnGUI; needs no canvas, event system or input package. Partials: toolbar, log list, details, input with suggestions, resize strip, hotkeys.
 
interface  IConsoleBackend

interface  IConsoleParser< T >

interface  IConsoleResultConverter
 Turns what a command returned into something the console prints or awaits: a value, a Task or an IEnumerator. Lets a game add its own awaitables (UniTask) without the console knowing them; add through ConsoleHub.AddResultConverter. More...
