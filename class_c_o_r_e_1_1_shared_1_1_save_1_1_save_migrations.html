Detailed Description

Migrations of save files. A file stores the CurrentVersion it was written with (Data.SaveFileBase.FormatVersion); reading an older file runs every migration above its version, in order, on the raw json — before it becomes objects, so renamed and moved fields can still be read. Register at boot, before the first save is read. A component's own data migrates with Data.SaveGameBaseComponentData.Migrate.
