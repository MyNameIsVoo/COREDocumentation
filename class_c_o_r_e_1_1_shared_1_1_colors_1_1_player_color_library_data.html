Detailed Description

Represents a user's custom color palette data: palettes a plugin or a game ships beside ColorLibraryData. Every asset of this type under a Resources folder is added to the ColorLibrary when the editor loads and when the game starts, so its colours are found by hash before anything is generated; adding a palette to the data itself (and generating) gives it enum tags on top.
