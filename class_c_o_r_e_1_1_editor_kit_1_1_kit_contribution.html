Detailed Description

Something a package adds to a kit window — a settings page, a setup check, a debugger page. Any concrete subclass with a parameterless constructor in any editor assembly is found by itself (KitContributions.All<T>) and belongs to the KitModule of its assembly; nothing is registered by hand.
