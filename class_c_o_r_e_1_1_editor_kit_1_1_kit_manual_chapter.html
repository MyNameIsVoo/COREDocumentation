Detailed Description

One page of a manual: a Markdown file in a package's Editor/Manual/<language> folder, with its place written on top:

id: config-editor (unique; a package prefixes its own: crafting/setup) title: Config Editor group: Editor tools (the sidebar heading, in the chapter's language) groupOrder: 50 (groups by this; a base uses 10–70, add-ons 100 and up) order: 10 (chapters within the group)

module: core (optional; else the module whose RootFolder holds the file)
