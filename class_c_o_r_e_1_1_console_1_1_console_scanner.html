Detailed Description

Reflection over assemblies and objects: finds the ConsoleCommandAttribute members, the ConsoleParserAttribute classes and the old [IngameDebugConsole.ConsoleMethod] methods. Pure reflection, so it may run on a worker thread; the result is committed to a registry on the main thread.
