Detailed Description

Base of the scene components of the gamepad support (since v1.3): gets the InputHost through DI — injected by the container that creates the prefab, else by DiContainerRef.Container in Awake, else later by whoever calls Container.Inject (tests). OnAttach runs once the host is known and the component is enabled, OnDetach when it is disabled or the host changes; both are balanced, whatever the order of injection and enabling.
